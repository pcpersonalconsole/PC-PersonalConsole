4. YOUR DATA

The Software stores its settings, profiles, themes, dictionaries, desktop layout and
diagnostic logs in a single folder inside your Documents folder. Removing the
Software does not delete that folder; your configuration is left in place and is
picked up again if you reinstall.

Saved credentials, if you use that feature, are held separately in your local
application data folder rather than with the rest of your settings, so that they are
never copied to a synchronised or cloud folder. They are encrypted with the Windows
Data Protection API and bound to your Windows user account on that computer; they
cannot be read on another machine and are not transmitted anywhere.

The Software does not collect analytics and does not transmit your data. The only
network request it makes is the update check, which contacts GitHub only when you
press the button that performs it.
